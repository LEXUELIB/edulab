# 平面几何技能约定

## 坐标系约定

- 数学坐标系：x 轴向右，y 轴向上。
- 前端 Canvas 渲染：屏幕坐标与数学坐标一致（通过 CSS 变换翻转 y 轴）。
- 大多数题目中心在原点或坐标轴上。

## 建系策略

### 三角形
- 直角三角形：直角顶点放在原点，两直角边分别沿 x、y 轴。
- 等腰三角形：底边水平，顶点在 y 轴上。
- 等边三角形：底边水平，顶点在上。

### 四边形
- 平行四边形/矩形/正方形：一个顶点在原点，一边沿 x 轴。
- 梯形：两底边水平。

### 圆
- 圆心在原点或坐标轴上。

## 解法配方

### 距离类
1. 两点距离：`distance_points(a, b)`
2. 点到直线距离：`distance_point_line(p, line_p1, line_p2)`
3. 圆外一点到圆切线长：用勾股定理 `PT = sqrt(OP^2 - OT^2)`

### 角度类
1. 两直线夹角：`angle_between_lines(p1, p2, q1, q2)`
2. 三角形内角：`triangle_angles(a, b, c)`
3. 圆周角定理：圆周角 = 圆心角的一半

### 面积类
1. 三角形面积（坐标法）：`area_triangle(a, b, c)`
2. 平行四边形面积：`area_parallelogram(a, b, c)`
3. 梯形面积：`(上底 + 下底) × 高 / 2`

### 三角形全等/相似
1. 全等判定：SSS / SAS / ASA / HL
2. 相似判定：SSS / SAS / AA

### 圆相关
1. 切线性质：切线垂直于过切点的半径
2. 割线定理：PA × PB = PC × PD
3. 相交弦定理：PA × PB = PC × PD
4. 圆心角定理：等弧对等圆心角

## 辅助线常见做法

1. **中线**：连接顶点与对边中点
2. **高线**：从顶点向对边作垂线
3. **角平分线**：平分内角
4. **垂直平分线**：垂直且平分线段
5. **平行线**：过某点作已知直线的平行线
6. **延长线**：延长某线段
7. **连线**：连接两个关键点

## 交互范式

### 范围题
- 使用 `rangeBar` 展示理论范围
- 滑块驱动参数变化，实时重算目标量

### 定值题
- 使用 `constant` 指示器
- 显示"≡ 定值"

### 定点题
- 使用 `derived` 构造交点
- 用 `readouts` 实时显示坐标

### 辅助线题
- 使用 `segments` 或 `derived` 中的 `line_*` 类型
- 辅助线用 `dashed: true` 和 `color: "aux"`

## 自检清单

1. kernel 答案 == 答案卡 `lesson.answer` == 末步骤展示值
2. 坐标一致性：Python 端坐标 == 前端 board 坐标
3. 图形渲染：三角形/四边形/圆正确显示
4. 辅助线：虚线、标注正确
5. 读数：实时更新正确
6. KaTeX 公式渲染正常
7. 无控制台报错

## 扩展指南

### 加题型
1. 在 `planar_kernel.py` 中添加求解函数
2. 在 `generate.py` 中添加 `build_*` 函数
3. 在 `REGISTRY` 中注册

### 加图形
1. 在 `shapes.py` 中添加图形构造函数
2. 在 `geometry.html` 的 `draw()` 函数中添加渲染逻辑

### 加交互构造
1. 在 `geometry.html` 的 `buildScene()` switch 中添加 case
2. 在 `problem-schema.md` 中登记

## 代码风格

- 变量名：snake_case
- 函数名：snake_case
- LaTeX 输出：用 `pk.tex()` 函数
- 精确计算：所有数值用 sympy 计算，避免硬编码

## 命名约定

- 点：大写字母（A, B, C...）
- 向量：加箭头符号（$\vec{AB}$）
- 线段：两点字母（AB, BC...）
- 角度：三个字母或单个字母（$\angle ABC$, $\angle A$）
- 三角形：$\triangle ABC$
